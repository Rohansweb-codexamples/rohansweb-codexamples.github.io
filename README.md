# Rohans Web — GitHub Edition

A modern GitHub Pages recreation/rebuild of the current Rohans Web homepage.

## Publish
1. Create a GitHub repository.
2. Upload `index.html`.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)`.
5. Save.

## Customise
Replace the placeholder links for RohanOS, your blog, submissions and any new projects with their real URLs.
